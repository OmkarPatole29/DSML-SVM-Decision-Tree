# SVM and Decision Tree Classification Using Iris Dataset

## Description

This project implements Support Vector Machine (SVM) and Decision Tree algorithms for classification using the Iris dataset in Python.

## Experiments

- **SVM:** Implements Support Vector Machine for flower classification.
- **Decision Tree:** Implements Decision Tree classification.
- **Performance Analysis:** Compares both models using accuracy score.

## Dataset

- Iris dataset from Scikit-learn.
- 150 flower samples.
- 4 input features.
- 3 flower classes: Setosa, Versicolor, and Virginica.

## Technologies Used

- Python
- Scikit-learn
- Pandas
- Jupyter Notebook

## Algorithms Used

1. Support Vector Machine (SVM)
2. Decision Tree Classifier

## How to Run

1. Install the required libraries:

   `pip install scikit-learn pandas jupyter`

2. Open Jupyter Notebook.
3. Open `SVM_Decision_Tree_Iris.ipynb`.
4. Run each cell in order.

## Objective

To implement classification algorithms and compare their performance using the Iris dataset.

## Conclusion

Both SVM and Decision Tree algorithms were implemented successfully. Their classification performance was evaluated using accuracy score and compared on the same testing dataset.
